# 0002 – Pixel art at 640x360

**Date:** 2026-10-23 · **Status:** accepted

## Decision
- Base resolution **640x360**, window opens at 1280x720.
- Stretch mode `viewport`, scale mode `integer` (sharp pixels at 720p, 1080p, 1440p, 4K).
- Default texture filter **nearest**.
- Tile size **16px**. Player is roughly 10x14 px for now.
- Renderer: **Compatibility** (best for 2D, also allows a web build later).

## Why
Pixel art is quick to produce for a small team, and 640x360 scales cleanly to common screen sizes.

## Consequences
Changing resolution later means redrawing or rescaling all art, so treat this as fixed unless the team decides otherwise.
