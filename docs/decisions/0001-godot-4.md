# 0001 – Godot 4 over Unity

**Date:** 2026-10-23 · **Status:** accepted

## Context
3-person team making a simple 2D vertical platformer, with most code written using AI.

## Decision
Use Godot 4.7 with GDScript.

## Why
- Scenes, scripts and resources are short plain-text files, so the AI can read and edit everything, not just scripts.
- Godot runs headless from the command line, so the AI can run tests and catch errors itself.
- Lightweight, free, and strong 2D tools.

## Consequences
- AI tools sometimes mix up Godot 3 and 4 syntax; `CLAUDE.md` forbids Godot 3 APIs.
- Everyone must use the same Godot version (4.7.x).
